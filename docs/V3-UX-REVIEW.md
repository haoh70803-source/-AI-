## 剩余可用性问题

- P1：AI事实误报会增加运营核对成本，尤其编号放在数字句之后、跨句假设与一般建议。当前有警告不代表一定错，无警告也不代表正确。
- P1：真实通知样稿出现占位符，课程样稿可能多写解释，用户不能稳定直接使用所有生成结果。
- P1：实际操作团队的任务入口理解、核心返工量和耗时尚未测；自动化点击不能代替真人测试。
- P2：仅整份锁定，长篇局部内容没有永久锁；本轮不重复V2或追加段落架构。

已有匿名样稿与评分模板可后续复用。用户先表示本人评阅，随后要求AI自行测试，本轮没有人工评分。人工自然度和创意结论保持 NOT TESTED；AI审阅发现事实失败，不能把“流程可完成”写成“运营无需返工”。
