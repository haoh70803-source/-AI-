## 1. 两种体验，一个产品

| 维度 | Dark Studio | Light Edition |
| --- | --- | --- |
| 体验目标 | 内容优先、专业密度、长时间工作 | 清晰入口、强排版、成果展示 |
| 色彩 | 中性黑灰，避免深蓝底与霓虹紫 | 白色、浅灰，中性黑文字 |
| 导航 | 64px 图标栏，当前页红色细线 | 同一图标栏与功能；白色表面 |
| 首页 Hero | 左侧文案、右侧品牌视觉 | 居中强标题、下方大幅品牌视觉 |
| 项目卡片 | 精细描边、16px 间隔、紧凑元信息 | 白色表面、24px 间隔、更宽松内距 |
| 创作工作区 | 项目上下文 / 对话 / 成果三栏 | 同一三栏，纸张式成果、更大内距 |
| 内容中心 | 大幅项目封面 + 密集内容网格 | 扩大封面和标题，留白更多 |

“Dark Studio”仅为视觉体验名称，不将历史 Studio 提升为产品中心。AI 创作页在产品架构中仍是 Project Workspace。

## 3. CSS Tokens

唯一主题入口：`html[data-theme="dark|light"]`。语义 Tokens 在 `tokens.css` 中定义，组件在 `styles.css` 中消费。同一组件 DOM、事件处理和数据适用于两套主题。

| Token | Dark | Light | 使用 |
| --- | --- | --- | --- |
| `--bg` | #111113 | #f5f5f7 | 页面、工作底板 |
| `--rail` | #0a0a0b | #ffffff | 图标导航 |
| `--surface` | #1b1b1e | #ffffff | 卡片、对话、纸张 |
| `--surface-2` | #232326 | #f0f0f2 | 次级表面、选中状态 |
| `--surface-3` | #2c2c30 | #e9e9ec | 进度槽与更深层次 |
| `--ink` | #f1f1f0 | #1d1d1f | 主文字 |
| `--muted` | #a4a4aa | #66666c | 正文与次级文字 |
| `--quiet` | #8d8d95 | #707077 | 元信息 |
| `--border` | #303034 | #dedee3 | 默认边界 |
| `--border-strong` | #48484e | #bfbfc6 | 输入框与交互边界 |
| `--action` | #eeeeec | #242426 | 主操作 |
| `--on-action` | #171719 | #ffffff | 主操作文字 |
| `--accent` | #ed7772 | #ac2c29 | 小面积强调、焦点 |
| `--accent-soft` | #382321 | #f9eae8 | 技能等低饱和强调背景 |
| `--page-pad` | 36px | 48px | 桌面外边距 |
| `--section-gap` | 36px | 56px | 内容段间距 |
| `--card-gap` | 16px | 24px | 卡片网格间距 |
| `--card-pad` | 16px | 22px | 卡片内边距 |

主题变量不只切换颜色，也切换密度。所有主题共用 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64px 间距标尺；控件圆角 8px、卡片 12px、面板 16px；动效 180ms。内容最大宽度 1520px。

字阶：系统无衬线字体栈，中文优先 PingFang SC / Microsoft YaHei；桌面 Hero 深色 34–48px、浅色 42–68px，手机统一 32px；正文 12–14px；元信息 9–11px。工作区侧栏元信息较紧凑，后续正式接入需结合真实用户可读性测试进一步调整。

## 5. 状态与交互

- 主题：顶部两项互斥按钮，使用 `aria-pressed`。查询参数优先于保存偏好；主题使用独立 `xinworld.prototype.theme` 键。直接变更根属性，不重建页面，保留编辑器、搜索、模型和输入状态。
- 项目：创建表单有必填名称、长度限制与可选初始想法；仅创建浏览器本地示例项目。
- 对话：输入可编辑；发送时短暂禁用发送按钮；固定示例回复明确标为演示；用户输入经过 HTML 转义。
- 技能：允许 0 个，演示开关可添加或移除品牌叙事技能；不将技能选中作为发送前提。
- 成果：直接编辑正文；修改后显示未保存；显式保存至本地存储；可下载 Markdown。存储失败反馈导出替代方案。
- 文件：文件选择只保留文件名，不上传、不读取内容、不解析。导入按钮引导到工作区继续开始。
- 内容：全部 / 成果 / 资料 / 收藏、名称与项目搜索、状态筛选、网格 / 列表切换、可逆收藏、无匹配空态及清除条件。
- 详情：原生 dialog，支持 Escape 与点遮罩关闭；可返回对应示例项目。
- 辅助交互：全局搜索、消息说明、账户说明和设计说明弹窗都有可见响应。

本地文稿为单份演示草稿，跨项目入口展示共享示例工作区；不模拟正式 Project scope 或独立持久化。这一限制需在正式接入前替换为已有服务提供的真实项目数据。

## 6. 响应式与可访问性

- >1200px：四列封面，创作三栏。
- ≤1200px：页面外距 26px、三列封面、压缩上下文栏。
- ≤980px：两列封面；隐藏上下文栏，保留对话与成果双栏。
- ≤640px：页面外距 18px，图标栏变底部导航；Hero 纵向；成果展示上下排列；创作采用对话 / 编辑两项面板切换。
- 主题和断点 Tokens 采用相同 CSS 特异性，避免浅色桌面间距覆盖移动间距。
- 提供跳到主内容、可见键盘焦点、图标控件标签、图片替代文字、原生表单、语义分区和 live status。
- 收藏与主题等状态具有可读标签，不单独依赖颜色。
- `prefers-reduced-motion` 禁用过渡与动画。
- 本轮验证覆盖 1440px 桌面、390px 手机，以及 768px 平板横向溢出；未声称完成正式 WCAG 或辅助技术审计。
