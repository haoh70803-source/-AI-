# 素材来源

- `logo-original.svg`：完整复制用户提供的 `E:/素材ui图片/logo(1).svg`，原路径与几何不变。
- `brand-mark.svg`：从原 SVG 的 `mark` 提取原始红点与三条弧线，修改 viewBox 以适配图标。app.js 内联同一几何，通过 currentColor 适配弧线颜色，红点固定 #c53532。
- `horizon.png`：2026-10-10 使用内置 imagegen 技能生成；银色水平环、红色圆点、沙地与地平线，用于品牌延展视觉。原图复制到本目录后使用，未修改或替代 Logo。
- `architecture.svg`：本轮原创代码矢量插画，暖灰拱门与空间光影。
- `editorial.svg`：本轮原创代码矢量编辑封面，慢生活与地平线。
- `research.svg`：本轮原创代码矢量研究封面，球体、轨道与观察概念。
- 图标：app.js 内的简洁线性 SVG 图形，按统一 24px viewBox / 1.5px 描边绘制。

用户深色参考截图用于窄导航、精细层次和封面网格；苹果截图用于排版、留白和大型展示。参考图未作为成品截图使用，未复制其中图片、产品信息或 Logo。未使用低分辨率旧首页参考缩略图或外部图片 CDN。

所有项目和成果封面均为原型示例，不宣称真实生成记录或实际用户资产。
