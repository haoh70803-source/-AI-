# 鑫世界生成内容质量契约 V1

## 适用范围

本契约适用于 Studio、内容学习及后续明确建设的组合、方法和创作能力。Provider 和模型可以变化，事实真实性、来源、成熟度和内容质量红线不能随模型变化。

## 输入优先级

1. 用户本次明确输入和限制；
2. 用户或公司的已确认事实；
3. 用户自己的真实案例；
4. CreatorProfile 中已确认的信息；
5. 用户明确保存的长期表达偏好；
6. 本次明确选择且适合当前任务的方法；
7. 外部参考方法、结构和表达策略；
8. 外部案例与参考证据；
9. 第三方写作参考。

低优先级内容不能覆盖高优先级事实。一次修改、收藏或生成不能自动成为长期偏好。

## 事实红线

模型不能编造或迁移客户、收入、成绩、项目、经历、数字、产品能力和已完成事项，也不能把计划写成已经完成。

事实不足时，依次选择：不用该事实；改成不冒充亲历的表达；如果该事实是内容成立的关键条件，明确要求用户补充或确认。不能为了稿件完整而虚构案例。

外部素材可以贡献方法、判断、结构、论证思路、角度和表达策略，但不能贡献作者身份、客户、收入、数据、经历、成绩和高度独特原句。

## 内容与表达

- 一篇内容保持一个清楚的主要意思，段落之间有推进，不重复堆同义句。
- 案例服务观点，方法对应问题，结尾不突然增加没有铺垫的新结论。
- 具体对象、动作和场景优先于“重视用户、持续输出价值、提升转化、打造差异化、赋能业务、形成闭环”等正确废话。
- 普通口播优先说人话、自然节奏和短句；避免连续排比、机械的首先其次最后、空洞升华、反复“不是 A 而是 B”、强行冲突和固定爆款模板。
- 学习外部内容应学习逻辑并重新创作，禁止近义替换、拼接和洗稿。
- 用户选择的方法不一定都适合本次内容；不强制把多个方法全部塞进稿件。

## 系统责任

模型输出永远只是候选，必须经过结构校验、SourceRef 校验、事实归属校验和成熟度/保存规则。模型不能创造来源、决定事实归属、绕过保存门或直接升级长期资产。

本轮不建立 AI Judge、质量分数、第二模型审稿、多模型投票或推荐算法。真实语义质量继续使用固定样本做真实模型验收。
