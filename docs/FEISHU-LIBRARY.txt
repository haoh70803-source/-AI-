鑫世界 AI工作台1.2：飞书资料源接入操作说明

入口：http://localhost:3032/library/feishu
也可从“知识与资料 → 资料库 → 飞书资料”进入。

你需要完成的步骤
1. 在 https://open.feishu.cn/app 创建企业自建应用。保存 App ID 和 App Secret，密钥仅在工作台的配置页输入，不要发到聊天或写入文档。
2. 开通 docx:document:readonly（读取新版文档）。如果资料链接是 /wiki/，同时开通 wiki:wiki:readonly。发布应用版本，完成企业审批；确认应用可用范围包括负责授权的人员。
3. 请文档所有者在目标文档右上角“…”→“添加文档应用”添加该应用，授予“可阅读”权限。知识库文档还需确认目标节点可读。开放平台的 API 权限与具体文档的阅读权限都需要具备。找不到应用时，先检查是否发布、审批及可用范围。
4. 在工作台“飞书资料”页填写 App ID、App Secret，勾选启用连接、自动同步；确认选入的资料可以共享给当前工作空间所有有效成员，然后保存连接。
5. 点击“测试连接”验证应用凭证。测试连接成功仅代表凭证有效，还需通过具体文档同步确认阅读授权。
6. 添加 2–3 份方法论、案例、品牌资料的飞书链接，选择对应资料用途。支持 https://团队.feishu.cn/docx/… 和 /wiki/…（节点内容为新版文档）。每个工作空间首期最多订阅 20 份文档。
7. 检查每份文档的状态为“已建立索引”，再输入相关主题验证检索。打开“查看资料”可查看同步正文，“飞书原文”可直达源文档。

更新与移除
自动同步每 5 分钟执行一次，需要本地工作台服务保持运行。可随时点击“立即同步”。分析文案、生成项目助手脚本前，会刷新并核验授权，再检索相关片段；结果附实际使用的飞书资料原文链接。
文档更新会替换正文及索引。删除、撤销阅读授权或读取失败时，该文档退出检索索引并清空缓存正文；重新获得授权后同步可恢复。
“停止订阅”清空本地正文和检索片段。“恢复订阅”后需重新同步。“断开连接”移除该连接的本地正文与索引，不删除已经生成的历史结果。

范围与实际状态
首期读取新版文档的纯文本正文，采用中文与英文关键词检索。表格、附件、图片文字、整库递归及语义向量检索不在首期范围。
管理员、所有者管理连接和订阅；有效成员可检索同一工作空间内已确认共享的资料。工作台使用应用授权读取资料，不模拟每个成员自己的飞书权限。
密钥在服务器端加密保存，不在页面或接口中回显。
代码测试使用隔离的测试工作空间和模拟飞书响应。真实飞书连接，需要你完成上述配置及文档授权后验证；实际模型生成还需工作台已有的模型服务可用。

闭环验收建议
添加文档并检索 → 修改源正文后刷新，确认新内容出现 → 生成文案，确认附原文链接 → 撤销应用对其中一份文档的阅读权限，刷新并确认资料退出检索 → 恢复授权，再次同步恢复。
