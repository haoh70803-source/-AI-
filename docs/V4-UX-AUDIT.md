## 已确认的可用性缺陷

| 编号 | 修复前 | 修改 |
| --- | --- | --- |
| UX01 | 首页演示数据看起来像真实指标 | 移除首页隐藏来源的参数，复用原有演示标识及复制/导出来源。 |
| UX02 | 成果版本/保存提示分散，预览藏在最末端 | 汇总保存状态；正文顶部编辑/预览切换，预览渲染当前编辑值并明确未保存。 |
| UX03 | 历史只有序号/标题，长正文层级弱 | 补充时间、恢复保留历史说明，正文区域换行且独立滚动。 |
| UX04 | 保存失败仍显示正在保存 | 失败清除进行状态，保留正文和错误提示。 |
| UX05 | 保存后历史数据被清空但历史仍展开 | 切换到已保存成果时关闭旧历史，重新打开时读取当前版本。 |
| UX06 | 异步同版本刷新也调用showArtifact，清空用户选区 | 仅更高版本触发同步，不覆盖未保存内容。 |
| UX07 | 保存后正文版本已更新，列表短暂保留旧版本；长标题挤压移动端 | 当前列表立即使用编辑器版本/标题；窗口标题最多两行，完整名称仍可在名称输入与title查看。 |

沿用深色表面、青色/紫色重点和原布局，仅扩展现有CSS；没有复杂动画、新编辑器或平行成果状态。
