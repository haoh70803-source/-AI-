# 鑫世界 Studio 产品语言契约 v1

## 一级入口

核心工作流固定为：

- 创作：开始创作、管理创作任务、选择创作方法、生成和修改稿件。
- 资料：保存资料、生成文字稿、看懂内容、提炼并进入创作。
- 研究：研究博主和优秀作品，拆解结构并沉淀可复用内容。
- 方法：查看和管理创作方法，在创作时选择使用。

设置、团队和系统管理属于账户 / 管理入口，不作为核心工作流模块。

项目管理保留在“创作”工作流内；“全部创作”是后续可使用的入口名称，不新增独立一级导航。

| 内部概念 | 用户名称 | 使用规则 |
| --- | --- | --- |

| MethodAsset / MethodVersion | 创作方法 | 普通运营页面不显示内部模型名。 |

## 词语取舍

### 保留

- “资料”：覆盖资料库、原始来源和资料详情，避免同一对象反复改名。
- “创作”：覆盖开始任务、项目工作台和进入创作的动作。
- “研究”：覆盖发现、对标和内容拆解。
- “创作方法”：覆盖方法库和创作时的方法选择。

### 替换

| 当前可能出现的词 | 统一为 |
| --- | --- |
| 开始创作、创建项目、新建创作 | 开始创作 |
| 项目、工作项目 | 创作 / 创作任务 |
| 素材、原始素材 | 资料；只有说明媒体文件本身时保留“原始素材”。 |
| 项目资料 | 资料；在创作工作台中需要强调归属时可使用“当前创作资料”。 |
| 灵感研究 | 研究 |
| 创作方式 | 创作方法 |
| 加入项目、加入 Studio | 加入当前创作 |
| 开始生成 | 生成初稿；只有明确对象是文字稿时使用“生成文字稿”。 |

### 仅特定上下文允许

- “项目”：仅用于 URL、权限、项目管理等需要精确区分的上下文；普通导航和 CTA 不作为一级产品名。
- “原始素材”：仅用于播放、下载或核对媒体文件的上下文。
- “转写”：用于“重新转写”等明确动作；结果名称统一为“文字稿”。
- “发布任务”：仅用于发布管理页面，不提前扩展为一级导航。

## 核心动作

- 开始创作
- 进入创作
- 加入当前创作
- 生成文字稿
- 重新转写
- 内容理解
- 内容提炼
- 保存为创作方法
- 使用这个方法
- 生成初稿
- 换个开头
- 精简
- 改写
- 下载

同一语义不并列使用“创建项目 / 开始工作 / 创建内容 / 新建创作 / 加入项目 / 加入 Studio / 开始生成”。

## 页面壳约定

核心页面使用一致的标题、副标题、返回逻辑、主操作、空状态、错误状态、区块标题和次要操作表达；具体布局可以因工作流不同而保留差异。

- 创作页：主操作是“开始创作”。
- 资料页：主操作是“添加资料”。
- 资料详情：主线是“文字稿 → 内容理解 → 内容提炼 → 进入创作”。
- 研究页：主操作是“开始研究”。
- 方法页：主操作是查看、管理和选择创作方法；当前保存入口来自研究结果，不虚构独立的新建动作。

普通运营页面不显示 Provider、Worker、Queue、FactGate、ownership、MethodVersion、AIRun、ASR、Prisma 等工程实现名；管理员诊断信息可以放在受限的高级详情中。

## 跨页面连续性

- 资料 → 创作：保留当前资料引用，并明确进入一个创作任务。
- 研究 → 创作：保留研究结果或对标依据；本轮只统一入口和表达，不重写研究业务。
- 方法 → 创作：方法页和创作工作台统一使用“使用这个方法”；若当前能力不足，记录为后续缺口，不虚构动作。

## 发布入口说明

`/calendar` 本轮不加入一级导航。发布仍是后续核心工作流候选，当前只保留现有入口与能力。
