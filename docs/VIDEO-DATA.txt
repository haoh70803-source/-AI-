鑫世界工作台 1.2 · 抖音数据中台使用说明

入口
功能首页 http://localhost:3032/home 独立展示短视频数据中台。
创作工作台：http://localhost:3032/dashboard（不含数据中台）。
完整大盘：http://localhost:3032/short-video
今日任务：http://localhost:3032/short-video/tasks
导航：首页 → 数据中台；工作台 → 创作；内容创作 → 今日任务。
本轮仅支持抖音；账号、内容和任务保留平台字段，后续可扩展其他平台的数据适配。

首次使用
1. 所有者或管理员在“账号矩阵”登记账号名称和编号。抖音号或内部编号均可；编号需以字母/数字开头，可含点、短横线、下划线，同一空间内唯一。
2. 点击“录入数据”，选择账号和日期，录入当日累计指标与数据截至时间。
3. 批量数据可使用“导入 CSV”：下载模板、填写数据、选择文件、检查预览的新增与更新数量，确认后整批保存。
4. 登记内容台账并关联已有创作项目，填写运营阶段。
5. 在“今日任务”添加任务类型、标题、账号、负责人、关联内容、截止时间及说明。
6. 勾选完成，或点击“去执行”进入落地页，保存执行记录、开始执行、打开关联创作项目或抖音创作者平台。

指标口径
今日总流量按播放量或曝光量分别查看，不将两项相加。
今日总互动 = 点赞 + 评论 + 分享 + 收藏，是次数，不是去重人数。
今日净增粉丝 = 新增 − 取关，支持负数，绿增红减。
指标为有效账号的已录入快照，页面显示今日已录入/有效账号数。
未录入与已录入0不同：未录入显示“—”及图表空档；真实录入0才显示0。
曝光量可留空。所选账号中存在缺失曝光量时，不展示冒充完整的曝光合计。
昨日和上周同期比较仅在相关日期账号覆盖完整且基准非零时计算；今日阶段快照对照历史全日，不代表同一小时的同比。
页面时区为北京时间（UTC+08:00）。数据截至时间来自录入，刷新只重新读取本地快照，不会自动采集抖音数据，也不修改快照时间。
同一账号同一日期只有一份记录，重录或CSV导入更新整日指标，不是追加累加。采用版本号防止并发覆盖，前后数据写入操作审计。

CSV格式
UTF-8，可含BOM。每批1–500行且文件小于240KB。
严格表头：账号编号,日期,播放量,曝光量,点赞,评论,分享,收藏,净增粉丝,负面评论,限流确认,完整日,数据截至
账号编号必须已经登记；日期格式 YYYY-MM-DD；数值为整数，曝光量可空；净增粉丝可为负数。
限流确认与完整日填写“是”或“否”；今日只能填写阶段快照，完整日只用于历史日期。
数据截至采用含时区的ISO时间，例如 2026-10-08T10:00:00+08:00，不得填写未来或早于数据日期的时间。
单账号单指标上限20亿；日期可录入过去五年。负面评论不得多于总评论。
文件引号、重复账号日期、未知账号、错误日期或非法数值会被拒绝；整批保存失败会回滚，不会留下半批结果。
预览后若别人修改了同一记录，需重新预览，避免覆盖对方结果。
导出遵从所选账号及数据范围，并对文本公式做转义。

预警
流量下降：该账号昨日和前日均标记完整日，前日播放量不少于1000，昨日下降至少50%。
限流：仅显示人工录入的限流确认，不根据低播放量推断平台限流。
评论异常：今日至少10条评论，人工标记的负面评论占比达到20%。
预警铃铛展示数量和下拉详情，可跳转账号数据或任务列表。缺少数据不会被当成正常经营。

任务与内容生命周期
支持发布视频、直播、回复评论、剪辑、投流；截止时间必填。
默认列表包含今日任务和未完成逾期任务，可按全部日期、仅逾期及状态筛选。
待开始/进行中为存储状态，已逾期按截止时间实时计算；完成后记录完成时间。
可重新打开已完成任务；完成任务需先重新打开再延期，新的截止时间必须晚于当前时间。
勾选立即反馈，保存失败恢复原状态。点击去执行直接进入该任务落地页。
任务完成只表示执行记录完成，不自动声称视频已在抖音发布，也不自动改变内容生命周期。
运营内容阶段包括选题、制作中、待审核、待发布、已发布和已归档；这里的阶段不替代原有创作项目的正式审核与发布流程。
原发布审核、创作和账号权限不变。抖音实际发布仍在其创作者平台执行，本轮没有自动发布接口。

权限与运行
有效空间成员可查看；VIEWER不能写入。
账号登记/归档仅OWNER或ADMIN操作；EDITOR可录入数据、登记内容及创建指派给自己的任务。
任务负责人、创建者、OWNER或ADMIN可修改任务；其他成员的写入会被服务端拒绝。
归档账号退出有效账号统计，保留历史，可以恢复；既有任务仍可执行。
