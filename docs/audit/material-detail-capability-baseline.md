# 资料详情能力基线

资料详情路径：`/library/[id]`

以下能力必须长期保留，并由资料详情 unit / E2E 回归测试持续保护：

1. 查看原始资料
2. 视频/音频访问
3. 查看文字稿
4. 编辑文字稿
5. 复制文字稿
6. 重新转写
7. 服务不可用时仍显示重转入口和原因
8. 内容理解
9. 内容理解详细信息展开
10. 内容提炼
11. 提炼入口始终可发现
12. 待确认内部内容可编辑
13. 确认
14. 拒绝
15. ownership / FactGate 安全约束
16. 下载
17. 进入创作
18. 失败后保留旧结果
19. 资料处理进度
20. 普通运营不暴露工程错误信息

> 后续任何资料详情 UI Reset 都必须通过该能力基线对应测试，不允许为了视觉简化删除能力。
