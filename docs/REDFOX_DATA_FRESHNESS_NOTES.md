# RedFox 数据新鲜度说明

## 当前语义

RedFox 搜索、榜单、账号作品和作品详情来自不同接口。搜索排序和互动指标是服务返回时的观察值，不代表平台的绝对实时状态，也不能被描述为“实时全量数据”。

当前系统明确区分：

- `publishedAt`：作品在原平台的发布时间，服务未返回时为空。
- `providerFetchedAt`：本系统最近一次成功取得该作品信息的时间。
- `providerCrawlTime`：服务明确返回其采集时间时才记录；当前作品 Adapter 没有可靠字段，因此保持为空。

## 用户触发的更新

已收录且具有 RedFox 作品标识或原始链接的素材，可由 Editor、Admin 或 Owner 手动点击“更新作品数据”。只有该点击会发起作品详情请求；打开素材详情、页面刷新和状态轮询都不会调用 RedFox。

手动更新只修改标准化作品信息和数据更新时间：

- 不创建新 `SourceItem`
- 不重新下载媒体
- 不创建 `IngestJob`
- 不触发或覆盖 Transcript

缺失数据保持 `null`，界面隐藏或显示“数据服务未返回”，不得用 `0` 冒充。

## 后续工作

V1.2A 不统一搜索、趋势、账号作品与创作者详情的新鲜度。后续版本可在真实调用成本、缓存时长和用户需求经过试用验证后，再设计 RedFox 趋势与创作者 freshness 策略。

本地 Storage 保存位置的选择和迁移也不在本阶段，后续以 Storage Location Configuration 独立处理。
