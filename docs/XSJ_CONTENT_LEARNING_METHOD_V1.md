# 鑫世界内容学习方法 V1

## 目的

系统从真实内容中发现值得学习的东西，判断它现在是稳定方法、待观察观点、单一案例还是普通内容，再把真正可迁移的部分整理成以后能帮助创作的资产。

这套方法只描述鑫世界产品如何学习内容，不是开发 Skill，也不建立 Agent、知识库或自动晋级流程。

## 工作流程

发现 → 判断 → 深化 → 留下 → 未来组合。

1. 发现：先从文字稿中找候选精华，不做普通摘要，不要求固定数量。
2. 判断：核对真实依据、迁移价值、实际信息量和使用边界。
3. 深化：员工决定留下后，再补充怎么使用、适合场景和不适合照搬的边界。
4. 留下：只有成熟、可执行的方法才进入“我的方法”。
5. 未来组合：跨内容组合属于后续阶段，单条视频不会自动晋级成稳定规律。

## 六个产品概念

- 依据：文字稿中的真实位置和原文。
- 精华：这条内容真正值得学习的部分。
- 判断：它目前属于哪种成熟度。
- 用法：决定留下后补充的实际步骤。
- 适用：适合使用的场景。
- 边界：不能直接照搬或尚未得到支持的部分。

## 四种成熟度

- 值得留下：依据清楚、有迁移价值、不是正确废话，并且可以补充成可执行方法。
- 可以先记着观察：有启发，但证据、范围或边界还不够成熟。
- 只是一个不错的案例：主要价值来自一次经历、客户、结果或故事，不能从单一样本推出规律。
- 暂时不用沉淀：内容普通、一次性、偏宣传或只有泛泛观点。

“做好内容”“重视用户”“坚持努力”“提高价值”“保持专业”等没有新增判断或行动信息的表述，不作为长期资产。

## 两种学习方式

“综合看看有什么值得学”只回答内容教了什么，输出候选精华、成熟度和文字稿位置。

“重点看看这条文案怎么写”只回答内容如何被组织和表达，包括命题、切口、开头、推进、骨架、论据作用、可迁移策略、不应照搬的部分和二改方向。它不做原稿近义改写，也不与内容里讲授的方法混在同一契约中。

模型只引用本次输入中明确提供的来源编号；页面原文由程序取回。不存在的编号不会成为依据，也不会制造原文。

## 真实来源索引

“可验证的真实来源”不等同于 ASR segment：

- 文字稿有真实 segments 时，运行时生成 `S001` 一类短引用，解析回真实 segment、顺序、原文和已有的真实时间。
- 文字稿只有 fullText 时，程序按固定算法切成 `T001` 一类文本块，保留 block index、字符起止位置和完全来自 fullText 的原文，不写回 Transcript，也不伪造时间。

S/T 编号只在一次模型输入中帮助引用，不是长期数据库身份。一次提炼保存的是当时 Transcript 版本和已经解析出的真实原文；文字稿后来更新时，新任务重新生成索引，旧成功结果不会跟着漂移。

模型只能提出本次存在的来源编号。不存在的编号直接过滤，不猜最近片段、不做模糊替代，也不允许模型补写所谓原文。

## 方法资产边界

MethodAsset 只承接成熟、可用于创作的 method、process、framework、checklist、decision_rule 和 copy_structure。principle、hypothesis、case_reference 与普通 insight 保留在学习结果中，不强塞进方法资产。

当前 M1、M4、M7 三种 MethodVersion 来源互斥。若未来 M8 需要为 MethodAsset 增加第四种来源关系，必须先重新评估来源模型，不连续增加 `sourceM8Id`、`sourceM9Id` 一类字段。

## 事实与外部参考

外部素材只提供参考证据和表达方法，不能证明我们的客户、收入、身份、经历、项目或成绩。生成时的优先级是：本次明确输入 > 自有确认事实和案例 > CreatorProfile 真实信息 > 长期偏好 > 本次选择的方法 > 外部参考证据。

## 页面动作预算

普通业务区域保持一个主要动作和最多两个直接可见的次要动作。素材页已经由“去创作”“内容拆解”“提炼这条视频”占满预算；后续能力通过二级选择、结果内动作、更多菜单、对话或按场景出现，不再增加素材页主按钮。
